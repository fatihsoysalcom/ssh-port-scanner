# SSH Port Scanner

This Python script demonstrates how to perform a basic SSH port scan on a given host. It attempts to connect to the default SSH port (22) and reports whether the port is open or closed, providing a safe way to check SSH service availability.

## Language

`python`

## How to Run

Save the code as `ssh_scanner.py`. Run from your terminal: `python ssh_scanner.py <target_host>` (e.g., `python ssh_scanner.py example.com`)
